## 4. Reddit — r/SideProject (or r/InternetIsBeautiful)

**Title:** I built a free game that teaches students how money actually works — you live on your first paycheck and try not to blow it

**Body:**

> I kept seeing friends graduate without ever budgeting, so I built Prafund.
>
> It's a financial life simulator: you pick a career, get a fictional monthly
> paycheck, and make the decisions adults actually face — rent, insurance,
> investing. The market uses real tickers (S&P 500, Apple, NVIDIA, Bitcoin)
> with clearly-labeled simulated prices, so you can experience volatility
> without losing anything.
>
> What makes it different from a spreadsheet: it's a game. The simulator
> quietly rewards the boring stuff — steady investing, emergency fund,
> insurance before splurges — the same way real life does. There's also a
> built-in glossary so you learn the terms you're using.
>
> 100% free, no account needed to play, works on mobile.
>
> Link: https://pranaygollu2009-create.github.io/prafund/
> Source code: https://github.com/pranaygollu2009-create/prafund
>
> Feedback welcome — especially from students or teachers!

## 5. Show HN (news.ycombinator.com)

**Title:** Show HN: Prafund – a financial life simulator that teaches money without losing it

**Body:**

> Hi HN! I built Prafund because most financial literacy tools are static
> quizzes that don't change behavior.
>
> Prafund is a simulator: pick a career, receive a fictional paycheck, and
> make real tradeoffs — housing, insurance, savings rate, index funds vs.
> single stocks. Markets use real tickers with simulated, honestly-labeled
> prices (no API keys needed). The engine quietly rewards the boring choices
> real compounding rewards.
>
> Tech: TanStack Start + React + TypeScript, Supabase for optional cloud
> saves, deployed as a static SPA on GitHub Pages. Open source:
> https://github.com/pranaygollu2009-create/prafund
>
> Try it: https://pranaygollu2009-create.github.io/prafund/
>
> Would love feedback, particularly from students and educators. Roadmap
> includes a classrooms mode for teachers.

## Tips before posting

1. Post the X/LinkedIn/Reddit ones separately — don't cross-post the same text everywhere on the same day.
2. Best time for student audiences: evenings and weekends.
3. On Reddit, reply to every comment in the first 2 hours — engagement drives visibility.
4. Pin the best-performing post, then add the link to your school's WhatsApp groups you're in.
5. After the is-a.dev domain approves, replace links with https://prafund.is-a.dev/ for a cleaner look.
